# KautionGuard test assets

Generated test corpus used for the end-to-end test runs (mock suite:
41/41 API checks; live-provider run: see the session notes). All leases
are fictional. Drop any file into the matching page of the app, or feed
it to the API endpoints directly.

## documents/ — Contract Decoder (`/contract`, `POST /api/decode-contract`)

| File | What it tests |
| --- | --- |
| `live-lease-munich.pdf` | German lease, auto-detect → DE. Deposit €2,450 = 3.5× the €700 cold rent (over the § 551 BGB cap), €175 Kleinreparaturen clause with no yearly ceiling, rigid Schönheitsreparaturen schedule. |
| `custom-lease-de.pdf` | German lease (Hamburg): €200 repair clause with no cap, deposit 4× the €900 cold rent. |
| `custom-lease-uk.pdf` | UK AST (London): £500 exit-cleaning charge, 8-week deposit. Auto-detect → UK. |
| `blank.pdf` | Valid PDF with no text — decode must answer 400 "No extractable text in PDF". |
| `notapdf.pdf` | Text file with a .pdf name — decode must answer 400 (magic-byte check). |

The seeded demo leases (Berlin / London / Paris) are not duplicated
here; they are generated by `backend/seed_demo_cache.py` and served by
the running backend.

Note from the live run: against the real providers, concept prompts
("water stain", "dark stain", auto-detected "burn mark") returned
no-match for these images from the test sandbox, and several calls
exceeded the app timeouts — retest from a normal network before
judging SAM quality.

## video/ — Walkthrough (`/evidence`, `POST /api/process-walkthrough`)

| File | What it tests |
| --- | --- |
| `live-walkthrough.mp4` | Generated 7s 640×360 clip with a test pattern + 520 Hz tone (no speech — exercises the silent-vision fallback). |
| `walkthrough-custom.mp4` | Generated 6s clip, same idea, different pattern/duration. |
| `notavideo.mp4` | Plain-text file with an .mp4 name — walkthrough must reject it (502 with FFmpeg detail). |
| `walkthrough-silent.mp4` | **Silent** (no audio track at all): 15s slow pan across the water-damaged parquet photo. Exercises the silent-vision fallback (`detection_mode: silent_vision_auto`). |
| `walkthrough-narrated.mp4` | **Narrated**: 28.3s (under 30s), three short scenes with a clear voice-over (synthesised speech) matching what is on screen — the transcription should return three spoken parts, one per defect. |

Narration transcript of `walkthrough-narrated.mp4` (for checking the
voice transcription against):

1. (0:00, parquet floor) "The living room parquet by the bathroom door
   is water damaged and lifting, because water soaked in through the
   unsealed doorway. The boards must be replaced, the threshold
   sealed."
2. (0:10, bathroom) "In the bathroom, black mould covers the shower
   corner and ceiling, fed by shower steam and poor ventilation. It is
   a health risk and must be removed properly."
3. (0:20, ceiling) "A large yellow water stain spreads across the
   bedroom ceiling, caused by a leak above it. The leak must be found
   and fixed before the ceiling is repainted."
